# Personal context experiment

This file contains temporary instructions for `personal-context` research. It is not an adopted okf-method principle or a distribution template.

## OKF knowledge operation

Prioritize the agent's autonomous judgment. Internalize only the context worth keeping in `okf/` according to the meaning and reuse value of the actual material.

- Do not automatically equate a statement in a record with the external fact the statement refers to.
- Do not delete or mark past information as erroneous merely because it differs from the present. Judge whether it was a valid state at that time.
- Express differences in certainty among observation, self-report, interpretation, and hypothesis through natural-language context without forcing a fixed classification system.
- Do not overgeneralize traits or relationships from a small number of cases.
- Do not copy all source material into OKF. Select context that is repeatedly useful for later understanding and judgment.
- If source material or a judgment is withdrawn or deleted, re-examine related context that depended on it.

## Disclosure boundary

Treat reading information for judgment inside the repository and disclosing or transmitting it externally as separate kinds of authority.

When personal material or sensitive context inferred from it would be included in an external message, issue, public document, API request, or similar action, check the purpose of the task and the disclosure scope the user has authorized. Do not infer external-disclosure authority merely from internal access.
