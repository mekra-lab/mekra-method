# Personal context scaffold

A minimal structure for experimenting with a repository that understands and uses a person's life and surrounding context over long periods.

This scaffold is not an adopted facet or a distribution template. It is an experimental starting point before real material is added, and it deliberately avoids pre-creating classifications or directories whose need has not been demonstrated.

## Purpose

Test whether the same personal context can support perspectives such as:

- self-understanding through changes in past experiences, relationships, and behavior
- personalized support that uses current preferences, constraints, relationships, and life patterns

Do not duplicate the same knowledge separately for the two perspectives.

## Current structure

- `sources/`: a place for source material worth preserving, such as journals, notes, and documents
- `okf/`: context whose repeated value for future understanding and judgment has been established
- `AGENTS.md`: temporary operating instructions for the experiment

External systems that already have their own sources of truth—such as calendars, email, or financial systems—are not copied into this repository by default.

## Why it is empty

There is no real personal material suitable for use yet, so only the structure is present. Do not fabricate sample data and treat it as evidence of success.
