# OKF v0.1 → v0.2

This document summarizes only the changes in the official v0.2 specification that directly affect existing bundles. The canonical source for detailed rules is [official SPEC §13](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md#13-changes-from-v01).

## Renames that require migration

| v0.1 | v0.2 |
| --- | --- |
| `timestamp` | Replaced by `generated.at`; record the producer in `generated.by` |
| Body `# Citations` list | Replaced by frontmatter `sources` |

A v0.2 consumer can read the legacy forms as fallbacks, but when migrating a bundle it is better to move to the new fields.

## Optional additions

Credibility signals under `sources`, along with `generated`, `verified`, `status`, `stale_after`, and fields related to `Attested Computation`, are additive features. Introduce them when there is an actual need for provenance, verification, freshness, or computation assurance; do not invent values merely to populate the format.

## Checklist

- Has the target version in the bundle-root `index.md` been updated?
- Have concepts using legacy fields been found and converted while preserving meaning?
- Do tools and agent instructions read and write the new field names?
- Are documents without the new optional fields still accepted?
